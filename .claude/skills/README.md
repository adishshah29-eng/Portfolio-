# Web-design agent skills

This directory contains the web-design skill set from
[devinilabs/pro-skill](https://github.com/devinilabs/pro-skill), itself a
mirror of [MengTo/Skills](https://github.com/MengTo/Skills) by Meng To,
used under the MIT License (see `LICENSE`).

Only the `agent-skills/web-design/` category was installed (landing pages,
GSAP/Three.js/WebGL effects, layout systems, visual styles, etc.). Binary
demo assets (images, videos) were stripped to keep the repository small;
each skill's `SKILL.md` / `REFERENCES.md` / scripts are kept intact.

Upstream snapshot: MengTo/Skills commit `22bacc4`.
